# AI-Enhanced Industrial Production Forecasting and Decision Support System

## Project Overview

This project develops an intelligent time-series forecasting system for industrial production data.

The system extends a research study comparing Triple Exponential Smoothing (TESM) and SARIMA for forecasting India's Food Products Index of Industrial Production (IIP).

## Baseline Models

- Triple Exponential Smoothing (TESM / Holt-Winters)
- SARIMA

## Planned Enhancements

- Multiple IIP sectors
- Automatic SARIMA selection
- Walk-forward validation
- SARIMAX and external variables
- Random Forest
- XGBoost
- LSTM
- GRU
- Anomaly detection
- Structural-break detection
- Prediction intervals
- Model explainability
- Interactive forecasting dashboard
